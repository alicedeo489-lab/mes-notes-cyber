## Jour 1 - Beepy / Morse
- Les bips = Morse
- Pi court = . , Pi long = -
- Outil : Traducteur Morse en ligne
- Flag : InIt{B33PY_M0RS3_1S_C00L}

## Jour 2 - Base64
- Code bizarre qui finit souvent par = ou ==
- Exemple : SW5JdHtCQVNFNjRfSVNfRUFTWX0=
- Outil : base64decode.org -> Decode
- Flag : InIt{BASE64_IS_EASY}
- Leçon : Base64 c'est de l'encodage, pas du chiffrement. Tout le monde peut décoder.
